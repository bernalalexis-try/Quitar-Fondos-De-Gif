# Quitar-Fondos-De-Gif
Editor web para sacarle el fondo a un GIF sin perder la animación.

Marcás el color de fondo con el cuentagotas y se borra solo en los cuadros donde
realmente aparece. Lo que quede lo retocás a mano con la goma, y cada cuadro
guarda su propia máscara: borrar algo en uno no toca a los demás. 

También podés poner imágenes encima arrastrándolas al lienzo. Se exporta como GIF animado con
transparencia o como PNG suelto.
